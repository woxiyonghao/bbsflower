Functional Modules

核心功能规格矩阵

📚

1. 花种百科库

收录上百种常见与进阶室内外植物，按难度、光照、浇水频率分类。每条记录含学名、俗名、原产地、适宜温度、湿度、土壤与病虫害提示。数据预置本地，支持关键词搜索与筛选。

🪴

2. 我的花盆档案

添加真实植物实例，关联百科条目，记录购买/入手日期、位置（阳台/窗台）、花盆尺寸与备注。支持自定义昵称，形成个人绿意收藏。

💧

3. 浇水与施肥打卡

一键记录浇水、施肥、喷雾等操作，自动计算下次建议时间。支持“今日待办”列表与日历视图，连续打卡天数清晰可见。

📷

4. 成长照片日记

从本地相册选择照片附加到指定花盆与日期，形成时间线成长轨迹。支持简单文字笔记，回顾新叶、开花、换盆瞬间。

🗓️

5. 养护日历与热力图

月历直观展示每日养护动作，热力图呈现坚持频率。轻触日期可回看当天为哪些花做了什么功课。

🔔

6. 本地智能提醒

基于花种特性与用户上次操作时间，纯本地计算生成提醒。支持系统通知与应用内角标，不联网也能准时提醒浇水。

🏆

7. 养护成就徽章

连续打卡、成功开花、成功繁殖、克服病虫害等均可获得徽章。已获得与下一档进度同屏展示，激励长期陪伴。

✍️

8. 观察笔记与回顾

自由记录叶片变化、病虫害观察、季节调整心得。支持按年汇总养护天数、最长连续与常护花种，生成精美回顾卡片。

🧩

9. 桌面服务卡片

支持鸿蒙服务卡片（小、中、大）。小尺寸：今日待浇水数量；中尺寸：待办列表 + 一句话花语；大尺寸：热力图概览 + 快捷打卡入口。同样适配深色模式。

Care System

养护体系与交互逻辑

💧

浇水与日常打卡逻辑

• 打卡操作：一键记录浇水 / 施肥 / 喷雾 / 修剪等动作，自动关联花盆档案
• 周期计算：根据花种预设周期 + 用户上次操作时间，本地推算下次提醒
• 补记机制：支持补记最近 7 天操作，保持日历与连续天数连续
• 足迹回顾：轻触日历日期即可回看当天为哪些花做了什么

🏆

成就徽章累积逻辑

• 五大类别：连续养护、开花成功、繁殖成功、病虫害克服、百科阅读
• 累积方式：打卡、记录开花、添加繁殖笔记、完成百科阅读均可获得
• 进度展示：已获得徽章与正在冲刺的下一档同屏呈现
• 本地计算：全部徽章逻辑在本机完成，无需联网验证

📷

成长照片与笔记

• 本地选图：仅使用系统相册选择器，不申请相机实时拍摄权限（可按需扩展）
• 时间线：照片与笔记按日期挂载到对应花盆，形成成长故事
• 回顾卡片：支持生成水墨 / 花语风格回顾图，可保存到本地相册

📊

年度养护回顾

• 年度汇总：养护天数、最长连续、常护花种、开花次数统计
• 视觉呈现：生成精美回顾卡片（液态玻璃 + 花语元素）
• 数据范围：全部基于本地沙盒数据，隐私安全
